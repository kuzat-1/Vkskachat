# VK Video Downloader

Приложение для просмотра и скачивания видео с VK Video.

## Особенности

- Поиск видео по названию
- Просмотр видео внутри приложения
- Скачивание видео на устройство
- Поддержка разных качеств (240p, 360p, 480p, 720p, 1080p)
- Управление загрузками
- Локальный сервер для обработки запросов

## Установка

1. Убедитесь, что у вас установлен Flutter SDK
2. Клонируйте репозиторий
3. Выполните `flutter pub get`
4. Подключите устройство или запустите эмулятор
5. Выполните `flutter run`

## Требования

- Flutter 3.0+
- Android 5.0+ или iOS 11+

## Использование

1. Откройте приложение
2. Введите название видео в строке поиска или вставьте ссылку
3. Выберите нужное видео из результатов
4. Для просмотра нажмите на видео
5. Для скачивания нажмите кнопку "Скачать" и выберите качество

```
│   └── downloads_screen.dart # Экран загрузок

    └── video_card.dart       # Виджет карточки видео
```
