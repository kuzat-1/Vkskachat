# VK Video Viewer

Приложение для **просмотра видео из VK Video** внутри собственного видеоплеера.

> Проект развивается как просмотрщик: пользователь смотрит видео в приложении и не скачивает его на устройство.

## Что мы делаем

Мы превращаем проект из старого VK Video Downloader в полноценное приложение для просмотра видео.

### Основные возможности

- 🔎 Поиск видео по названию
- 🔗 Открытие видео по ссылке или ID VK
- ▶️ Просмотр видео прямо внутри приложения
- 🎬 Собственный видеоплеер вместо обязательного перехода в VK
- ⏯️ Play / Pause
- ⏩ Перемотка и управление прогрессом
- 🔊 Управление воспроизведением
- ⚙️ Выбор качества видео
- 🅰️ Режим «Авто» для выбора доступного качества
- 🖼️ Получение названия, длительности и обложки видео
- 📱 Интерфейс, оптимизированный для Android
- 🌐 Серверный слой для поиска и получения метаданных VK
- 🔄 Резервный способ получения видео, если основной источник недоступен
- 🛡️ Архитектура без передачи служебных VK-токенов пользователю

## Что НЕ делает приложение

- ❌ Не скачивает видео на устройство
- ❌ Не содержит раздела «Загрузки»
- ❌ Не предоставляет пользователю кнопку скачивания
- ❌ Не хранит скачанные видеофайлы

## Качество видео

Если VK предоставляет несколько вариантов качества, плеер показывает их пользователю.

Доступные варианты могут отличаться в зависимости от конкретного видео, например:

- 240p
- 360p
- 480p
- 720p
- 1080p

Режим **«Авто»** выбирает наиболее подходящий доступный вариант из полученных источников. В дальнейшем архитектуру можно расширить до полноценного адаптивного HLS/DASH-воспроизведения, если такой источник доступен.

## Архитектура

Приложение использует несколько уровней получения данных:

1. Серверный API — поиск, метаданные и разрешение видео.
2. VK API — получение информации о доступных источниках, когда это возможно.
3. Резервный механизм — обработка публичной страницы VK.
4. Flutter-плеер — воспроизведение доступного видеопотока внутри приложения.

Служебные данные и токены должны оставаться на серверной стороне и не попадать в клиентский код или интерфейс пользователя.

## Установка для разработки

1. Установите Flutter SDK.
2. Клонируйте репозиторий.
3. Выполните:

```bash
flutter pub get
```

4. Подключите Android-устройство или запустите эмулятор.
5. Запустите приложение:

```bash
flutter run
```
